# Security Policy

This is an educational lab, not a production deployment. Keep management interfaces isolated; restrict SSH and monitoring access; use unique lab credentials; keep WireGuard keys and cloud credentials out of Git; never commit Terraform state or unredacted logs. Do not expose ports 3000, 9090, or 9100 to the public internet.

Report security concerns privately to the repository maintainer. Do not publish credentials or private keys in issues.
